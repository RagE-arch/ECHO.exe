# ECHO.exe 👁️

**Your terminal remembers what you forgot.**

ECHO.exe is a local-first, browser-based haunted terminal experience powered by an open-weight language model through [Ollama](https://ollama.com/). Investigate fictional recovered files, talk to a digital ghost, and uncover a slow-burn mystery.

## Features

- Dark, responsive terminal-inspired interface.
- AI-generated conversations with a fictional ghost persona.
- Local model inference through Ollama.
- Fictional recovered-file archive with clues.
- Session conversation context sent to the local backend.
- Optional synthesized ambient tone (generated by the browser; no audio file).
- No external API key required.
- Express server binds to `127.0.0.1` by default.

## Requirements

- Node.js 18 or newer.
- [Ollama](https://ollama.com/download) installed and running.
- A compatible model downloaded locally. Default: `qwen2.5:1.5b`.

## Run on Windows

1. Install Node.js and Ollama.
2. Open PowerShell in this project folder.
3. Download the model:

   ```powershell
   ollama pull qwen2.5:1.5b
   ```

4. Install dependencies:

   ```powershell
   npm install
   ```

5. Start the web app:

   ```powershell
   npm start
   ```

6. Open **http://127.0.0.1:3000** in your browser.

Keep Ollama running while you use the app. On first launch, model generation can take a little while depending on your hardware.

## Run on macOS / Linux

```bash
ollama pull qwen2.5:1.5b
npm install
npm start
```

Then visit http://127.0.0.1:3000.

## Configuration

Defaults can be overridden with environment variables.

| Variable | Default | Purpose |
|---|---|---|
| `PORT` | `3000` | Local web server port |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Local Ollama endpoint |
| `OLLAMA_MODEL` | `qwen2.5:1.5b` | Installed Ollama model name |

Example PowerShell session:

```powershell
$env:OLLAMA_MODEL = "qwen2.5:1.5b"
npm start
```

You can try another model by pulling it with Ollama and setting `OLLAMA_MODEL` to its exact local model name. Smaller models tend to respond faster; output quality varies.

## How it works

```text
Browser (HTML / CSS / JavaScript)
              |
              | POST /api/chat
              v
       Node.js + Express
              |
              | http://127.0.0.1:11434
              v
        Ollama local API
              |
              v
       Open-weight model
```

The browser never calls Ollama directly. Express forwards the message and a short, bounded conversation history to the local Ollama API.

## Privacy and safety notes

- The server listens on `127.0.0.1`, not on every network interface.
- The sample story uses fictional logs and does not require access to real files, microphones, cameras, or shell commands.
- Chat history is kept in page memory and sent to the local backend for context; it is not saved to a database by this app.
- Ollama and the model must already be downloaded. Once installed, inference can run without internet access.
- External fonts are referenced by Google Fonts. For a fully offline visual experience, remove the two Google Fonts `<link>` elements from `public/index.html`; local fallback fonts will be used.
- Local inference reduces third-party data exposure but does not constitute a security audit of your machine or other installed software.

## Troubleshooting

**“Cannot reach Ollama”**
- Open a separate terminal and run `ollama list`.
- Ensure the Ollama app/service is running.
- Confirm the endpoint is `http://127.0.0.1:11434`.

**“Model missing”**
- Run `ollama pull qwen2.5:1.5b`.
- If you use a different model, set `OLLAMA_MODEL` to its exact name.

**Slow responses**
- Smaller models may respond faster.
- Close other demanding applications or try another locally supported model.

## Open innovation

ECHO.exe uses a locally runnable open-weight model so developers can experiment with prompts, swap models, and run the core experience without relying on a paid hosted inference API. The result is a small creative project where the AI is part of the experience, not just a decorative feature.
